此目录用于存放对外展示图片。建议只使用演示账号和脱敏数据，不要上传真实客户名称、手机号、邮箱、访问 IP、域名、订单、密钥或内部管理信息。

## 截图规范

- 推荐宽度：桌面端 1440–1920 px；移动端 390–430 px
- 建议格式：产品截图使用 PNG，照片或大图使用 WebP/JPG
- 统一浏览器尺寸、缩放比例和演示数据风格
- 隐藏浏览器书签、个人头像、通知和系统时间等无关信息
- 首图优先展示实际产品界面，不使用无法兑现的概念效果图
- 图片添加到仓库后，可在主 README 的核心能力之前增加产品预览区域

## 推荐的 README 图片写法

```markdown
![JLCH 数据看板](assets/dashboard.png)
```

## 对外发布检查

- 图片中没有真实个人信息或客户信息
- 没有内部域名、服务器地址和调试工具
- 没有测试报错、未完成按钮或敏感菜单
- 展示的功能在当前交付版本中确实可用
- 品牌名称、Logo、网址和联系方式保持一致
